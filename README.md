# 📋 Telegram-бот для приёма заявок с админ-панелью

Асинхронный Telegram-бот на **aiogram 3** с базой данных SQLite. Собирает заявки от пользователей (имя, телефон, комментарий), сохраняет их в базу и уведомляет администратора. Админ-панель позволяет просматривать статистику, последние заявки и выгружать все данные в CSV.

## ✨ Возможности

### Для пользователя
- 🚀 Команда `/start` запускает сценарий сбора данных.
- 🪜 Пошаговый FSM-сбор: имя → телефон → комментарий.
- ❌ Кнопка «Отмена» доступна на каждом шаге.
- 📨 Заявка сохраняется в базу данных и отправляется администратору в HTML-формате.

### Для администратора
- 🔧 Команда `/admin` открывает админ-панель с кнопками:
  - **📊 Статистика** — общее количество заявок.
  - **📋 Последние 5 заявок** — список последних заявок из БД.
  - **📤 Выгрузить в CSV** — генерация и отправка CSV-файла со всеми заявками.
- 🔒 Доступ к админ-панеле restricted по `ADMIN_ID` из `.env`.

## 🗄 База данных

Используется встроенная **SQLite** (`database.py`). Таблица `leads` содержит:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Автоинкрементный ID заявки |
| `user_id` | INTEGER | Telegram ID пользователя |
| `username` | TEXT | Username пользователя |
| `name` | TEXT | Имя, введённое пользователем |
| `phone` | TEXT | Номер телефона |
| `comment` | TEXT | Комментарий к заявке |
| `date_added` | TEXT | Дата и время создания (ISO-формат) |

## 🛠 Стек технологий

- **Python 3.10+**
- **aiogram 3** — фреймворк для Telegram Bot API
- **python-dotenv** — загрузка переменных окружения из `.env`
- **sqlite3** — база данных (встроенная в Python)
- **csv / io** — генерация CSV-выгрузки (встроенные в Python)
- **asyncio** — асинхронное выполнение

## 🚀 Пошаговая инструкция по запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/<your-username>/tg-bot.git
cd tg-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация:

- **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
- **Windows (cmd):**
  ```cmd
  venv\Scripts\activate.bat
  ```
- **Linux / macOS:**
  ```bash
  source venv/bin/activate
  ```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка файла `.env`

Создайте файл `.env` в корне проекта (или отредактируйте существующий) и укажите:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
```

- **BOT_TOKEN** — токен бота, полученный у [@BotFather](https://t.me/BotFather).
- **ADMIN_ID** — числовой Telegram ID администратора (узнать можно у [@userinfobot](https://t.me/userinfobot)).

> ⚠️ Файл `.env` добавлен в `.gitignore` — не коммитьте его в репозиторий!

### 5. Запуск бота

```bash
python bot.py
```

При старте автоматически создаётся файл `leads.db` с таблицей `leads`. После запуска в консоли появится лог `INFO`, а бот начнёт принимать сообщения.

## 💬 Как пользоваться ботом

### Обычный пользователь

1. Отправляет `/start`.
2. Вводит **имя**.
3. Вводит **номер телефона**.
4. Вводит **комментарий**.
5. Получает подтверждение — заявка сохранена и отправлена админу.

На любом шаге можно нажать **«Отмена»**.

### Администратор

1. Отправляет `/admin` — открывается меню с тремя кнопками.
2. **📊 Статистика** — показывает общее количество заявок.
3. **📋 Последние 5 заявок** — выводит список последних заявок с деталями.
4. **📤 Выгрузить в CSV** — отправляет файл `leads.csv` со всеми заявками из базы.
